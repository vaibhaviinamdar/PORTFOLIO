Project:1 Memory Game

Memory Card Game is a simple, single-player game that tests your memory and concentration. A set of cards with matching pairs is shuffled and placed face-down in a grid. The player flips two cards at a time; if they match, the cards stay face-up, otherwise they flip back after a short delay. The game ends when all pairs are found, and the goal is to complete it in as few moves and as little time as possible.

The game is built using HTML, CSS, and JavaScript. HTML defines the game container, stats bar (moves, timer), and a grid of card elements. CSS styles the layout, cards, and flip animations using transforms and transitions. JavaScript handles the core logic: creating a shuffled array of card data, rendering the grid, tracking flipped cards, checking for matches, updating moves and timer, and resetting the game when all pairs are matched.

Tech: HTML, CSS, JavaScript
